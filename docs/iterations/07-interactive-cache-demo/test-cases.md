# 7단계 구현 전 TC — 간소화한 로컬 캐시 시연

- 상태: 구현 전 계획. **아래 표는 계획이며 실행 결과가 아니다.** TC별 실제 증거와 범위 제한은 [검증 기록](verification.md)을 참조한다. 엄격한 OS 소유 증명·고아 자동 회수 시험은 범위 밖이다.
- 단위/통합은 각각 이중물과 실제 격리 자원으로 검증한다. 기존 사용자 캐시·DB와 기존 측정용 자원은 실행·삭제·변경하지 않는다. 통합 DB는 7단계 전용 시험 컬렉션만 쓴다.

| TC | 유형 / 연결 요구 | 사전 조건·실행 | 기대 결과 |
| --- | --- | --- | --- |
| TC-07-01 | 단위, REQ-07-001, REQ-07-003 | 빈 DB에 키 `a`/빈 값을 저장하고 같은 키를 값 `v2`로 갱신, 목록 조회 | 새 저장/수정 문구가 구별되고 목록은 한 항목이며 빈 값도 저장된 키로 취급 |
| TC-07-02 | 통합, REQ-07-002, REQ-07-004, REQ-07-006 | 새 전용 캐시에서 `a=v1` 저장→두 번 읽기→`a=v2` 수정→두 번 읽기 | 각 저장 뒤 캐시 DELETE 확인. 첫 읽기는 DB→캐시, 두 번째는 캐시. 수정 뒤 값은 두 번 모두 `v2` |
| TC-07-03 | 단위, REQ-07-002, REQ-07-006, REQ-07-008 | `a=v1`이 캐시에 있을 때 DB를 `v2`로 갱신하고 캐시 DELETE를 실패/시간 초과로 주입 | 저장 성공+안내. **캐시 전체가 즉시 꺼지고** 같은 키·다른 키의 후속 읽기는 DB; 추가 캐시 요청 없음 |
| TC-07-04 | 단위, REQ-07-004, REQ-07-006, REQ-07-008 | DB 미스 뒤 캐시 PUT에 시간 초과·응답 끊김/이상 응답 주입, 같은 키를 다시 저장·읽기 | 첫 DB 값은 fallback 문구로 표시, 그 서버 수명 동안 추가 캐시 GET/PUT/DELETE 없음. 지연된 PUT을 캐시 히트로 반환하지 않음 |
| TC-07-05 | 단위, REQ-07-004, REQ-07-008 | 캐시 GET에 연결 오류/500/503/잘못된 404 본문 주입 | 미스로 간주하거나 캐시 PUT하지 않음. 캐시 비활성화 후 DB 대체 읽기와 출처 기록 |
| TC-07-06 | 단위, REQ-07-002, REQ-07-008 | DB 쓰기 오류(시간 초과 포함) 주입 | 저장 실패, 캐시 내용 변경 호출 없음, 캐시 접근은 세션 동안 중단. DB 조회 실패 시 값 조작 없이 오류 |
| TC-07-07 | 통합, REQ-07-003, REQ-07-006, REQ-07-008, REQ-07-011 | 7단계 전용 DB에 값 저장, 캐시를 채우고 페이지 서버 재시작 | DB 키·기록은 보존. 새 빈 Mini Redis 자식만 기동·접속하며 첫 읽기는 DB→캐시. 새 서버는 이전 자식을 재연결하거나 임의로 종료하지 않음 |
| TC-07-08 | 단위, REQ-07-005 | 캐시 미스 상태에서 DB 직접 읽기 | DB 출처·값·시간 표시, Mini Redis 호출 없음, 다음 캐시 우선 읽기는 여전히 미스 |
| TC-07-09 | 단위, REQ-07-007 | 읽기·저장 성공, 실패, 없는 키, 기록의 마지막 잘린 행과 서버 재시작 | 성공 행만 출처별 횟수·평균·중앙값에 반영, 실패/없는 키 별도. 파일 자동 삭제 없음, 화면은 최근 50행만 표시 |
| TC-07-10 | 단위, REQ-07-009, REQ-07-010 | 빈 키·금지 문자·201자 키·64KiB 초과 PUT JSON·빈 값 입력 | 잘못된 입력은 쉬운 문장/400이며 DB·캐시 호출 없음. 빈 값은 허용하고 저장 메시지에는 내부 DB·캐시 용어 없음 |
| TC-07-11 | 통합, REQ-07-011, REQ-07-012 | 별도 임시 Mongo DB/컬렉션·전용 캐시로 정상 흐름 실행, 소스 의존 검색 | 시연은 전용 시험 컬렉션만 사용하고 기존 데이터·서비스에 접근하는 경로 없음(코드·설정 확인), 폐기한 성능 비교 웹 뷰 모듈 참조 없음, `mini_redis/` 제품 소스 변경 없음 |
| TC-07-12 | 단위/HTTP, REQ-07-013 | 외부 인터페이스 바인딩 시도, 다른 Origin/잘못된 Host·토큰으로 POST 저장·읽기 | 127.0.0.1 이외 접근 불가, 보호 실패 403, DB·캐시·기록 불변. 정상 같은 출처 요청은 처리 |

**구현 진행:** 핵심 흐름부터 TC별 RED→GREEN. 실제 통합 자원을 사용할 때는 7단계 자체 생성 자식·별도 시험 컬렉션만 대상으로 하며, 실행 결과·차단/한계는 나중에 `verification.md`에 기록한다. 간소화 설계와 이 TC는 독립 검증을 통과했다는 뜻이 아니다.
