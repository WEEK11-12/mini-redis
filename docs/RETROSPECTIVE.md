# 프로젝트 소감

## 지영은

이번 주차에는 AI 도구를 활용하면서 팀 협업을 진행하는 과정에서, 달라진 협업 방식에 적응하는 것이 가장 어려웠습니다. 어떤 방식으로 함께 작업할지부터 작업 단위를 어떻게 나누고 누구에게 어떤 작업을 할당할지까지, 전반적인 과정에서 고민이 많았습니다.

AI 도구를 사용하는 상황에 맞는 협업 방식은 아직 찾아가는 중입니다. 앞으로 여러 번 협업을 경험하면서 작업 분담과 진행 방식을 조금씩 다듬어 가야 방향이 잡힐 것 같습니다.

## 이현지

mini-react 때 정리한 AI 활용 방법을 다듬어 적용하다 보니 이번에는 훨씬 효율적으로 진행할 수 있었습니다. 지난번에는 AI 활용법을 익히는 데 집중하느라 개념 공부가 얕았는데, 이번에는 Redis와 DBMS 개념을 더 깊이 공부했고 설계와 기술 선택에도 적극적으로 참여했습니다.

진행 방식도 바꿨습니다. 지난번에는 요구사항과 설계를 한 번에 끝낸 뒤 구현만 나눠서 했는데, 실패할 가능성을 고려하지 않은 방식이었습니다. 이번에는 큰 방향만 잡은 뒤 구현을 네 단계로 나눴고, 단계마다 요구사항 정리 → 설계 → TC 작성 → 구현 → 검증 과정을 반복했습니다.

결과물보다 방법론에서 배운 게 많은 한 주였고, 앞으로도 이 방식을 계속 다듬어 갈 생각입니다.
