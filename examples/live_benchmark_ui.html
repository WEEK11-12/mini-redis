Mini Redis 실시간 성능 비교 (로컬 시연)

이 화면은 로컬 실행 서버를 통해 기존 측정기(examples/benchmark.py)를 새로 실행하고, 그 실행의 원자료만 보여 줍니다. 브라우저는 시간을 재지 않습니다. 다른 측정기·사용자와 동시에 실행하지 마세요.

준비 상태: 확인 중

작업

준비는 Docker 확인, 전용 MongoDB 컨테이너 기동, 읽기 전용 시드 검사를 합니다. 이번 준비에서 새로 만든 빈 전용 볼륨일 때만 최초 시드를 자동으로 만듭니다. 비교 실행은 시드 검사 → MongoDB 재시작 → 기동·설정 확인 뒤 측정기를 실행합니다.

Docker 자원

화면을 닫거나 서버를 종료해도 Docker 컨테이너 __CONTAINER__와 볼륨 __DATA__, __CONFIG__는 자동으로 중지·삭제되지 않습니다. 이 화면에는 정리 기능이 없습니다. 더 쓰지 않을 때는 화면 밖에서 전용 이름·소유 표지·볼륨 연결을 확인한 뒤 수동으로 정리하며, 진행 중이거나 회수가 확인되지 않은 작업이 있으면 정리하지 마세요.

결과 해석의 한계

이 결과는 한 로컬 호스트의 순차 HTTP 전체 흐름 비교입니다. OS/Docker 파일 캐시, 동시 부하, 원격 DB, 디스크 I/O는 통제·측정하지 않았습니다. 사전 시드 표본 읽기는 재시작 전에 하므로 OS/Docker 파일 캐시에 영향이 남을 수 있어, 6단계와 같은 캐시 상태라고 단정하지 않습니다. 준비·시드·재시작·서버 기동·상태 준비·표시 시간은 측정 수치에 포함하지 않습니다.
